# Getting Started

## Prerequisites

Make sure you have **Git** and **Node.js** installed.

```bash
git --version
node --version
npm --version

```

1. Clone the Repository

```bash
git clone https://github.com/deepeshcodes2709/my_portfolio.git
```

2. Go to the Project
```bash
cd my_portfolio
```

4. Install Dependencies
```bash
npm install
```

6. Run the Project
```bash
npm run dev
```

Open the URL shown in the terminal, usually:
```bash
http://localhost:5173/
```

Build for Production
```bah
npm run build
```

Preview Production Build
```bash
npm run preview
```

Stop Server
```bash
Ctrl + C
```
